Se connecter à votre espace pro

Votre espace pro, c’est là que vous reliez votre activité à Tikette : vos activités et créneaux, vos photos, vos réservations et la réception de vos paiements. Voici comment y entrer, en toute sécurité.

Première connexion, en 1 minute

  1. Ouvrez tikette.fr/pro/espace, ou touchez le bouton « Espace pro » en haut de tikette.fr/pro.
  2. Saisissez l’adresse e-mail de votre entreprise, celle à laquelle nous vous avons écrit pour vous ouvrir l’accès.
  3. Vous recevez un e-mail « Votre code espace pro » de contact@tikette.fr avec un code à 6 chiffres. Recopiez-le : c’est fait, vous êtes dans votre espace.

Pas de mot de passe à créer ni à retenir : à chaque connexion, un nouveau code vous est envoyé. Il est valable 1 heure et ne sert qu’une fois. Pas d’e-mail ? Regardez dans les indésirables, puis touchez « Renvoyer un code ».

Activez la double authentification (conseillé)

En plus du code par e-mail, un code affiché sur votre téléphone est demandé à chaque connexion. Même si quelqu’un accède à votre boîte mail, il ne peut pas entrer dans votre espace.

  1. Installez une appli d’authentification gratuite si vous n’en avez pas : Google Authenticator, Microsoft Authenticator, ou l’appli Mots de passe de l’iPhone.
  2. Dans votre espace pro : Paramètres › Compte et sécurité › Double authentification › Activer.
  3. Scannez le code QR avec l’appli, puis recopiez le code à 6 chiffres qu’elle affiche. C’est activé.

Ensuite, à chaque connexion : code reçu par e-mail, puis code de l’appli. Téléphone perdu ou changé ? Écrivez-nous depuis l’adresse de votre entreprise : après vérification, nous désactivons la double authentification pour que vous la réactiviez sur le nouveau téléphone.

Les bons réflexes

  • Tikette ne vous demandera jamais vos codes, ni par téléphone, ni par e-mail, ni par SMS. Si quelqu’un vous les demande, c’est une arnaque : ne répondez pas et prévenez-nous.
  • Vérifiez l’adresse avant de saisir votre e-mail : la seule bonne adresse commence par https://tikette.fr/pro/espace.
  • Nos e-mails viennent toujours de contact@tikette.fr.
  • Sur un ordinateur partagé, déconnectez-vous à la fin (bouton « Se déconnecter » du menu).
  • Vos paiements sont gérés par Stripe : Tikette ne voit jamais votre IBAN ni les cartes de vos clients.

Votre équipe

Ne partagez pas vos codes avec vos collègues : invitez-les plutôt. Dans Paramètres › Équipe, ajoutez l’adresse e-mail de chacun (15 personnes au plus). Ils se connectent avec leur propre adresse et leur propre code, et vous pouvez retirer un accès à tout moment.

Un souci pour vous connecter ?

  • « Cette adresse n’a pas encore d’espace pro » : utilisez l’adresse à laquelle nous vous avons écrit. Vous voulez en changer ? Une fois connecté : Paramètres › Compte et sécurité › E-mail de connexion.
  • Code refusé : prenez le dernier code reçu, en moins d’une heure.
  • Toujours bloqué ? Écrivez-nous à contact@tikette.fr, on vous répond vite.
